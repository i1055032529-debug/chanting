# 阶段 4.6：逐格扩建（第一部分）

开店准备页点击“逐格扩建”，餐厅场景会直接显示半透明、带亮色边框的可扩充地块。点击其中一格便立即铺设并扣款，无需打开表格或二次确认。每格 80×80 游戏像素，价格暂定 20 金币。只显示与原店面或已购地面相邻一步的空格；填好一格后，新的相邻位置随即出现。地块可持续向右或向下延伸，没有预先框定的 5×5 区域。左侧和上方是保留的店面边界；右侧、下方不绘制墙体，但未铺设区域仍不能通行。营业中不能扩建，同一格不会重复收费。可用金币仍需先扣除预留工资。

扩建模式和家具设备模式都可用面板上的四个方向按钮平移镜头；玩家可以连续点击场景中的扩充格，再进入家具设备界面把餐桌或功能设备放进新区域。经营时镜头会跟随主角。未购买的地块不能通行，也不能摆家具。新区域内的桌位会正常接客，员工和顾客按当前格子布局寻路。已购地块和新家具跨营业日保留，新游戏会重置。

房间地面由 `assets/backgrounds/tiles/floor.png` 的 80×80 位图重复铺成；上方墙面和左侧边框分别使用 `wall.png` 与 `border.png`。原背景只保留入口、墙面装饰和收银台的局部显示，不再作为整间餐厅的一张底图。三张图块均远小于 400KB，后续可以逐张替换。

`tests/test_expansion.gd` 覆盖场景内点击铺地、只展示一步相邻地块、向右超出旧预留范围、向下扩建、重复扣费、跨日与新游戏，以及扩建区餐桌、设备、顾客和员工路线。阶段 4.6 的经济平衡与长局试玩仍待完成；退出程序后的持久化属于此前暂缓的 4.4 存档。
