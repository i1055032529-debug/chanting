# 阶段 4.6：逐格扩建（第一部分）

开店准备页点击“逐格扩建”，在右侧五列、五行的地块图中自行选择相邻空格。每格 80×80 游戏像素，价格暂定 20 金币。已购、可购买、暂不可达的格子有不同颜色；只有与原店面或已购格子相邻的空格可以购买。确认前不付款，营业中不能扩建，同一格不会重复收费。可用金币仍需先扣除预留工资。

购买后自动进入家具设备界面。此时可用面板底部的左右按钮平移镜头，把餐桌或功能设备放进新区域；经营时镜头会跟随主角。未购买的地块不能通行，也不能摆家具。新区域内的桌位会正常接客，员工和顾客按当前格子布局寻路。已购地块和新家具跨营业日保留，新游戏会重置。

房间地面由 `assets/backgrounds/tiles/floor.png` 的 80×80 位图重复铺成；新增墙面和地板边框分别使用 `wall.png` 与 `border.png`。原背景只保留入口、墙面装饰和收银台的局部显示，不再作为整间餐厅的一张底图。三张图块均远小于 400KB，后续可以逐张替换。

`tests/test_expansion.gd` 覆盖逐格购买、连通规则、重复扣费、跨日与新游戏、扩建区域餐桌及顾客和员工路线。阶段 4.6 的经济平衡与长局试玩仍待完成；退出程序后的持久化属于此前暂缓的 4.4 存档。
