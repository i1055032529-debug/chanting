# 32 像素网格与素材规格

餐厅场景以 `LayoutRules.TILE_SIZE = 32` 为唯一扩建网格常量。每块地板贴图为 **64×64 px**，覆盖 **2×2 个 32×32 游戏像素的格子**。扩建仍一次购买 32×32 一格；若只购买了大地砖中的部分格子，渲染时只裁出对应的 32×32 区域。初始房间铺 38 列、20 行扩建格，也就是 19×10 块完整地砖，以维持原有场景面积。

贴图采用最近邻过滤。家具和角色的低分辨率图片可按整数倍显示，保留既有交互范围与视觉占地：

| 素材 | 图片尺寸 | 场景显示倍数 |
| --- | ---: | ---: |
| 地板 | 64×64（覆盖 2×2 格） | 1× |
| 餐桌 | 64×32 | 2× |
| 椅子 | 28×35 | 2× |
| 炉台、洗碗台、出餐台 | 64×48 | 2× |
| 厨师、顾客动画帧 | 32×44 | 2× |
| 收银台 | 64×19 | 4× |
| 菜品图集单格 | 64×64 | 按菜谱卡片尺寸显示 |

当前多数低分辨率素材由 `tools/build_pixel32_assets.swift` 根据项目中保留的原始图片重新采样生成。运行命令：`swift tools/build_pixel32_assets.swift`。餐桌贴图为单独制作的 64×32 像素图，不由该脚本覆盖。新增素材应保持透明背景、清晰像素块，并将物件的视觉宽高与碰撞及通行空间一起检查。上方墙面保留原画构图，缩为 608×65 px 后以 2× 显示。
