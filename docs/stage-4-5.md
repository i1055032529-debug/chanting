# 阶段 4.5：家具与设备

开店准备时点击“家具设备”，可在左侧面板选择现有餐桌并移动，也可花 40 金币购买第五张餐桌。进入布置后，点击餐厅地面或使用面板上的方向按钮调整半透明预览；绿色表示可放，红色表示与家具重叠、越界或阻断必要通路。点击“确认位置”才会生效并付款，“取消布置”会恢复原状。营业期间不能更改家具。

![新增餐桌的布置预览](stage-4-5-placement.webp)

新餐桌有独立的顶部订单卡，顾客会沿可通行地面走到座位，主角和员工都能正常上菜、收盘与清洁。原有餐桌调整后，员工会重建寻路路线。布局检查包括家具与设备的占地、入口至各餐桌和工作台的通路，以及操作点和座位附近的可达性。

烹饪设备可花 70 金币升级一次。升级后，主角小游戏和员工自动做菜的制作速度均提高 25%；面板会显示价格与效果。家具和设备使用经营账本分别记账，重复购买不会重复扣款。

![第五张餐桌与已升级设备](stage-4-5-upgraded.webp)

餐桌位置、购买状态和设备升级在当前游戏的跨营业日经营中保留；按“新游戏”会重置。由于按当前开发顺序暂缓 4.4 存档，退出程序后的持久化留待 4.4 实现。

`tests/test_layout_equipment.gd` 覆盖越界、重叠、可达性、购买与升级扣款、第五张桌的顾客到达/上菜/收盘、员工寻路、跨日与重置，以及员工空闲慢速走动和接单。两张图片由 `tests/capture_stage_4_5.gd` 从实际游戏场景生成，均小于 400KB。
