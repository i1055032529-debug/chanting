# 阶段一：实现与验收

日期：2026-09-23  
开发分支：`feature/stage-1-service-loop`  
本地运行环境：macOS / Apple M1 Pro / Godot 4.7.1

## 实现目标

一个顾客完成从进店、点单到付款离店的全过程，主角将餐盘送回回收台，桌子恢复可用，并能重复接待。

## 状态规则

```text
EMPTY → ARRIVING → WAITING → COOKING → READY → CARRIED
  ↑                                    ↑        │
  │                                    └─放回───┤
  │                                             ↓
  └─ CLEARING ← DIRTY ← LEAVING ← EATING ←───────┘
```

- 入店时预留餐桌；入座时生成唯一订单。
- 制作完成后只产生一份成品，必须从出餐台拿取。
- 付款只在用餐完成时发生一次，与玩家交互无关。
- 顾客离开后才允许收盘；拿起餐盘不立即恢复餐桌。
- 回收餐盘后才开放新顾客入店。
- 做菜、上菜、收盘都有唯一任务标识、订单关联、状态和执行者。
- 该版本只有主角执行者；未声称支持多员工原子领取或订单超时取消。

## 素材与已知边界

- 场景、人物和物品是原创程序绘制的像素占位图，无外部图片或素材授权依赖。
- 中文字体使用操作系统字体；正式发行时应加入可分发字体资源。
- 场景和界面主要在代码中创建，当前不是可以直接拖动布置的编辑器家具系统。
- 顾客采用单桌固定路线，暂不与主角互相阻挡。
- 顾客入店处保留主角边界墙，主角不能离开餐厅。
- 没有耐心倒计时、地面污渍、员工、采购、存档或扩建；均属于后续阶段。
- 尚未制作可下载的独立游戏安装包，可在 Godot 中运行。
